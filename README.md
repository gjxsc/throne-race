# 👑 Throne Race · 4位玩家，1位赢家，0个朋友

> 四人抢座 · 墙棋大逃杀。灵感来自 B 站 UP 主 **Toaster_ok** 的视频《[4位玩家，1位赢家，0个朋友](https://www.bilibili.com/video/BV1GoY16qEJD)》。
>
> 本仓库参考（fork 自）[breadbot86/throne-race](https://github.com/breadbot86/throne-race)（[原版试玩](https://breadbot86.github.io/throne-race/)），在此之上加入了四关卡地形生物、天灾系统、道具/传说道具体系、闯关模式与一整套「有想法」的 AI 等大量新玩法。

**▶ 立即游玩本仓库版本：<https://gjxsc.github.io/throne-race/>**

单文件网页游戏，零依赖、零构建，手机/电脑浏览器都能玩。

## 玩法

四名玩家从棋盘四边中点出发，中央是 **👑 王座**。轮流行动，每回合二选一：

1. **移动** —— 棋子走一格（上下左右），不能穿墙、不能叠人；贴脸的棋子可以**跳**过去
2. **放墙** —— 在任意位置放一堵占 2 格边的墙，永久存在，用你的颜色

**📱 触屏设备**：点格线先出高亮预览（方向、两格跨度、受影响格子），再点一次确认放墙；点格子直接走子。桌面端鼠标悬停即有预览，单击直接落墙。

**第一个踏上中央王座的人获胜。**

规则保护：不允许放墙把任何玩家彻底堵死——谁都得起码留一条活路。
没有队友，没有谈判。**4位玩家，1位赢家，0个朋友。**

## ☄️ 天灾系统

每 3 回合（全员各行动一次算 1 回合）随机降临一场天灾，各关皮肤换主题：

| 天灾 | 效果 |
|---|---|
| ☔ 酸雨 | 恰好腐蚀 5 堵墙（不足则全腐蚀），每人 +2 次放墙 |
| ⚡ 暴雷 | 劈中约 1/10 的格子，格上棋子眩晕 2 回合 |
| 🕳️ 地陷 | 固定 10 格塌陷 3 回合，塌上者掉回出生点 |
| 🌧️ 暴雨 | 冲走所有玩家道具，每人下回合多行动一次 |
| ☀️ 烈阳 | 点燃一排火墙，穿墙者被烧伤 |
| 🪤 天降陷阱 | 随机埋 5 个无主隐形陷阱（场上无主陷阱多时暂避） |
| 🪨 泥石流 | 整列滚石轰到底，碎墙（补偿封顶 +3）、卷走沿途棋子 |

| 关卡 | 机制 |
|---|---|

| 🏜️ 沙漠遗迹 | 🌪️ 暴风随机传送踩入者；🐪 骆驼骑上 5 回合每回合 +1 行动 |
| ❄️ 冰雪峡谷 | 🧊 冰面会碎；🌨️ 暴风雪游走，同格玩家被弹飞 |

## 🎁 道具系统

棋盘每隔几秒刷出 🎁 宝箱（场上最多 5 个，超时顶掉最旧），**走上去拾取**（道具箱上限 2）。**每个宝箱都有小概率直接开出传说道具**——开箱前无人知晓。

**普通道具（12 种）**：🧱 +1 堵墙；🔨 碎墙锤；🔋 技能恢复卡；🪤 埋陷阱；🌀 混乱对手；🛡️ 免疫护盾；💫 开箱即中眩晕；🍄 蘑菇（朝王座冲 2 格）；🐢 绿龟壳（直线滚射、撞墙反弹、反弹不认主）；🎁 假宝箱（骗敌人踩中眩晕 2）；🎲 命运骰子（掷 1~6 听天由命）；🪃 回旋镖（往返双击 + 捎回途中宝箱）。

**传说道具（8 种，个个改变格局）**：

| 道具 | 效果 |
|---|---|
| 💥 大爆炸 | 王座/棋子/墙全部随机重组（含你自己） |
| 🎯 天灾指定 | 标记对手：下次暴雷/泥石流必定命中 |
| 📢 大喇叭 | 4 格震动波：墙全碎、敌人被震飞到棋盘边缘 |
| ⛸️ 溜冰鞋 | 下一次移动直线冲到棋盘边缘，途中照常触发陷阱/宝箱/王座 |
| 🌀 蓝龟壳 | 自动锁定领跑者：眩晕 5 回合 + 碎 1 道具 |
| 💣 炸弹兵 | 抛 3 格 3×3 爆炸（小心炸到自己） |
| ⏳ 时之沙漏 | 其他所有玩家冻结 1 回合 |
| 🌑 日蚀 | 敌方人类全屏黑暗 1 回合（AI 停摆） |

**开箱有橡皮筋**（马里奥赛车式）：领跑者难开出攻击道具，垫底者难开出防御道具——逆转永远有可能。

**道具箱满时踩到宝箱**：宝箱开盖展示新道具，弹出选择面板——点选一件旧道具「替换」，或「不替换」放弃（宝箱均消失）。AI 同样会按道具价值表自动取舍。

## 🤖 AI

不只是会走路——

- **道具两层策略**：紧急拦截（对手将登座时倾泻控制）、威胁防御（领跑才开盾）、最优目标（炸弹评分选最优方向、doom 反标追击者），外加 35% 概率「随性开溜」保底释放，绝不做铁公鸡
- **需求驱动拾箱**：空箱主动绕路抢宝箱（预算 4 步），垫底者更贪婪（+2），领跑者专注冲刺（-1）
- **关卡生物感知**：避岩浆/暴风/碎冰/暴风雪，虫临砸前走出砸落带、龙冲顶前绕开中列
- **绝望赌搏**：落后 ≥3 步几乎必输时，主动踩暴风/暴风雪博随机传送、踩塌陷当回家捷径——按期望距离精确定价
- 感知场选路（Dijkstra 加权：地形危险/资源折扣），放墙带收益评估（拖对手 > 自损才放）

## 🏆 闯关模式

逐关解锁（进度本地保存），4 关为「一轮」：每关胜者得 👑，一轮结束进入**加冕结算**——展示各家王冠，随机抽 3 条规则（坑害之王/道具之王/疾步之王/天灾之王）各赠 1 冠，排出本轮名次。全通关后无限循环新一轮。结算严格校验完整 4 关数据（从中途关开打不算完整一轮）。

## 模式

| 模式 | 说明 |
|---|---|
| 经典 · 我打 3 个 AI | 传统回合制，你（蓝方）走一步 AI 走一步 |
| 经典 · 4 人同屏热座 | 传统回合制，4 人轮流操作 |
| **同步 · 实时乱斗** | 取消回合！你和 3 个 AI 同时行动 |
| **同步 · 4 AI 实时互坑（观战）** | 同步规则的纯观战，赢后 5 秒自动开下一局 |
| 观战 | 经典规则的 4 个 AI 互坑，自动续局 |
| **🌐 在线 · 好友联机** | 和不同设备的朋友真人对战，见下节 |

**同步模式规则**：每人 3 个操作点（上限 3）——走一步 / 放一堵墙各消耗 1 点；动作间隔 0.5 秒；每秒自动恢复 1 点。棋子头顶的白色气泡就是当前操作点，**攒点中的 AI 气泡会变金色**——它在蓄力，攒满后 0.5 秒一连发地爆发 2~4 手，小心！

**技能系统**（默认开启，设置里可关）：开局每人从 10 个技能随机抽出的 3 个候选中选 1 个，整局限用 1 次，免费即时——

| 技能 | 效果 |
| --- | --- |
| 💥 墙面爆破 | 击碎棋盘上任意一堵墙 |
| 👻 穿墙 | 穿过身边一堵墙，落到墙另一侧的空格 |
| 🪓 盗取道具 | 夺取一名对手道具箱里的 1 个道具 |
| 🔄 换位 | 与指定角色互换位置 |
| 🎨 换色 | 与指定角色互换颜色（棋子与墙） |
| ❄️ 定身术 | 指定角色 1 回合不可操作（同步模式冻结 3 秒） |
| 🎲 随机跳跃 | 随机传送到任意空格（不会落到王座附近） |
| 👑 王座随机换位 | 王座随机迁移到棋盘上另一处 |
| 🌀 指定角色随机换位 | 把指定角色随机传送到任意空格 |
| 🏃 疾跑 | 本回合可行动 2 次（同步模式 +2 操作点） |

侧栏还可调：**地图尺寸**（9×9 / 11×11 / 13×13 / 15×15，出生点到王座始终等距）、**每人墙数**（5~20）、AI 节奏（正常/极速）、音效。

## 在线对战（好友联机）

模式选 **🌐 在线 · 好友联机**：创建房间得到 4 位房间码，朋友选「加入」输码（或直接打开带 `?join=房码` 的邀请链接）即可进房。2~4 人开局，**空位由 AI 补位**（一个人开局就是「我打 3 个 AI」），有人中途掉线也是 AI 接管。房主开局可选四种玩法：

| 在线玩法 | 对应单机模式 |
|---|---|
| 经典 · 轮流行动（空位 AI 补位） | 经典 pve / 热座 |
| 同步 · 实时乱斗（空位 AI 补位） | 同步实时乱斗 |
| 观战 · 经典规则 AI 互坑 | 观战（4 AI 互坑），结束后自动下一局 |
| 观战 · 同步规则 AI 互坑 | 同步 4 AI 互坑观战，结束后自动下一局 |

赢了点「再来一局」无限续；道具、地图尺寸、墙数等设置开局时由房主锁定。

架构是「房主权威」：房主浏览器跑全部游戏逻辑（含 AI），服务器（Cloudflare Worker + Durable Object）只做房间管理和消息转发，所以 **GitHub Pages 上的静态页面照旧能用**，只需旁边部署一个免费的小服务器——见 **[server/README.md](server/README.md)**（wrangler 两条命令，免费额度即可长期玩）。

## 本地运行

无需安装任何东西：

```bash
git clone https://github.com/gjxsc/throne-race.git
open throne-race/index.html   # 或直接双击
```

URL 参数（调试/复现用）：`?seed=123`（固定随机种子，跳过规则弹窗）、`?mode=pve/hotseat/sync/syncspec/spectate/online`、`?size=15`、`?walls=20`、`?item=5`（宝箱刷新间隔秒）、`?skill=0`（关闭技能系统）、`?fast=1`、`?join=房码`（直连加入在线房间）、`?ws=wss://…`（临时指定联机服务器地址）。

**已知限制**：同步模式下游戏时钟跑在房主页面的动画帧里，房主把标签页切到后台（浏览器会暂停 rAF）全场会暂停——房主请保持页面在前台；经典模式无此问题。

## 技术

纯原生 HTML + Canvas + WebAudio，单文件零依赖：墙合法性校验（重叠/交叉/留路 BFS）、AI 感知场（地形加权 Dijkstra）+ 两层道具策略 + 需求拾箱 + 生物规避/赌搏、种子随机保证联机各端一致（房主权威 + 快照/事件双同步）、粒子彩带与合成音效。
