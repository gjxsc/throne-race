| 道具 | 图标 | 类型 | 效果 |
|---|---|---|---|

### 橡皮筋机制（开箱重掷）

- 排名：`allDists().dist`（BFS 距王座），小=领先；离场者不计
- **普通宝箱开箱时**（pickupAt 内，host 权威执行，走 `rnd()` 联机一致）：
  - **领跑者**开出攻击类（trap/confusion/hammer/绿龟壳/假宝箱）→ 50% 概率重掷（全池重摇一次，以重掷结果为准）
  - **垫底者**开出防御/回复类（wall/shield/restore/眩晕）→ 50% 概率重掷
  - 并列名次按 players 数组序；中间名次不调整
- 传说宝箱不参与重掷（10%+8 选 1 等权不变；蓝龟壳本身就是橡皮筋道具）

## 2. 实现锚点（沿用既有三链路架构）

- **ITEMS** +9 条（假宝箱/传说道具标 legendary）；`rollItemKind` 池扩充并**分类标注**（ATTACK/DEFENSE/DASH 集合常量）供橡皮筋判定
- **传说池** `LEGENDARY_KINDS` 扩为 8 个等权
- **pickupAt**：假箱判定先行 + 橡皮筋重掷钩子（普通箱定型后按开箱者名次调整一次）
- **新状态**：`fakeBoxes[]`（{x,y,o}，进快照）；`p.blindRounds`（日蚀，进快照）；沙漏复用 `frozenTurns/frozenUntil`
- **飞行体**（绿壳/回旋镖/蓝壳/炸弹）：host 即时算完整路径并结算，`netEv` 携带路径供各端重放动画（fx 移动体，逐格 100ms 表现）
- **三链路**：clickInvSlot（蘑菇/骰子/蓝壳/沙漏/日蚀=即时；绿壳/回旋镖/炸弹=方向选择模式，复用 pendingItem；假箱=脚下放置）、hostApplyAction 对应分校验、aiUseItems 规则
- **AI**：传说类持有即用（炸弹加自爆安全检查：自己不在 3×3 内）；蘑菇持有即用；绿壳/回旋镖=四方向模拟可命中 ahead[0] 才用；假箱=持有即放脚下；骰子=持有即掷
- **渲染**：假箱（暗金静止箱）、四色飞行体 fx、蓝壳弧线轨迹、炸弹抛物线+爆炸圈（quake 放大版）、沙漏金边光效、日蚀遮罩（canvas 全屏黑罩+半径 1 格透明圆，各端本地渲染仅当自己被日蚀）
- **回合钩子**：blindRounds 在回合推进处递减（AI 停摆=其回合跳过）

## 3. 边界情况

| 场景 | 行为 |
|---|---|
| 蘑菇冲刺第一步就被围死 | 停在原地，道具照常消耗（与溜冰鞋先例一致） |
| 绿壳反弹后命中使用者自己 | 会——壳不认主（害人害己，MK 味） |
| 假箱与真箱同格 | 假箱优先触发；真箱待下次经过 |
| 骰子⑥时道具箱满 | 作废（日志提示） |
| 回旋镖去回程同一目标 | 只中一次（去程标记，回程跳过） |
| 蓝壳目标在自己滑行途中离场 | 命中时刻重新锁定当前领跑者 |
| 炸弹抛出方向 3 格内是墙 | 炸弹停在墙前格爆炸（不穿墙） |
| 沙漏/日蚀连续使用 | 效果叠加（冻结 2 回合/遮罩延长），正常 |
| 日蚀时使用者自己也在别人黑暗里？ | 不会——每个日蚀只影响"使用时在场其他玩家"，使用者恒亮 |
